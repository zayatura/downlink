# Downlink Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Downlink, a native Rust menu-bar app for macOS that talks to a ZSA Voyager over raw HID, shows the flashed Oryx layout live, and switches the macOS input source to match the active keyboard layer. It replaces Keymapp and a Python layout-switcher service.

**Architecture:** A Cargo workspace of six crates:
- Pure protocol, session and engine logic is unit-tested without hardware.
- Thin glue crates wrap hidapi, the Oryx GraphQL API and macOS Text Input Sources.
- The app crate is an iced 0.14 `daemon` with a `tray-icon` menu-bar item and two on-demand windows (Layout and Settings).
- Phase 0 is a throwaway feasibility spike that answers the open questions in spec §4.6 before any production code is written.

**Tech Stack:** Rust (edition 2024, stable ≥ 1.90), iced 0.14 (`canvas`, `tokio`), tray-icon 0.26 (muda 0.21 menus), hidapi 2.6 (`macos-shared-device`), reqwest 0.13, core-foundation 0.10 / core-foundation-sys 0.8, objc2 0.6 / objc2-app-kit 0.3, toml 1, dirs 7, tracing 0.1 + tracing-subscriber 0.3 + tracing-appender 0.2, png 0.18, thiserror 2, tempfile 3 (tests).

**Spec:** `docs/superpowers/specs/2026-10-13-downlink-design.md`. Read it before starting. Sections 4 (protocol facts), 6 (behavior) and 8 (errors) are referenced throughout.

## Global Constraints

- **Toolchain:** stable Rust ≥ 1.90 (tray-icon 0.26 MSRV), `edition = "2024"`, workspace `resolver = "3"`, `rust-version = "1.90"`.
- **License:** MIT. Every crate sets `license.workspace = true`. Never copy code or comments from ZSA's GPL-2.0 sources (`zsa/qmk_modules`, `zsa/qmk_firmware`). The Voyager geometry table holds only numeric facts, plus a comment naming the source (spec §13).
- **Identity:** no real name, macOS username, work email, or absolute home path (`/Users/<name>/…`) in any committed file, commit message, test, fixture or log format. Commits are authored as `zayatura <zayatura@mailbox.org>`; this is already set in the repo-local git config, so don't change it. Bundle ID and LaunchAgent label: `com.zayatura.downlink`.
- **The user's custom input-source IDs** (they contain the macOS username) are never written into the repo. Examples and tests use `com.apple.keylayout.US`, `com.example.keylayout.*` or short fakes like `"en"`.
- **Platform isolation:** `cfg(target_os = …)` code lives only in `crates/input-source/src/{macos,unsupported}.rs` and `crates/downlink/src/platform/`. All other crates must compile and pass tests on Linux unchanged.
- **Keyboard facts (spec §4.2–4.3):** vendor ID `0x3297`, Voyager product ID `0x1977`, raw-HID usage page `0xFF60`, usage `0x61`, 32-byte reports. On host writes, a `0x00` report-ID byte goes in front of the 32-byte packet (33 bytes to hidapi). Stop byte `0xFE`.
- **Timing constants:** enumerate every 1 s; read timeout 100 ms; handshake timeout 2 s; open-failure backoff 1 s doubling to 10 s; heartbeat (`PAIRING_INIT`) after 5 s without any packet; HTTP timeout 15 s; current-source poll every 2 s while a window is open.
- **Oryx API:** `POST https://oryx.zsa.io/graphql`, one fetch per new revision, cached on disk. `User-Agent: Downlink/<version> (+https://github.com/zayatura/downlink)`, never anything personal.
- **Trademarks:** ZSA, Voyager, Oryx and Keymapp appear only descriptively ("for the ZSA Voyager"). The README states "not affiliated with or endorsed by ZSA Technology Labs".
- **Paths (spec §7):** macOS config `~/Library/Application Support/Downlink/config.toml`, cache `~/Library/Caches/Downlink/`, logs `~/Library/Logs/Downlink/`.
- **Every task ends green:** `cargo fmt --all -- --check`, `cargo clippy --workspace --all-targets -- -D warnings`, `cargo test --workspace`. (In Phase 0 these apply only to the spike's own crate.)
- **Commit messages** use Conventional Commit style (`feat(oryx-protocol): …`) and end with the line `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- **Human-in-the-loop steps** are marked **[HUMAN]**. They need your human partner to press keys, watch the menu bar, or approve macOS permission prompts. Ask, wait, and record what they report verbatim.

## Review Focus

These are the five conditions the spec implies but no feature test would naturally exercise, ranked by how likely they are to hurt a real user. Each has a pinning test in the task that owns the code.

1. **Garbage firmware-version string or USB serial.** Examples: non-alphanumeric characters, `../`, an empty part, no `/`, more than 32 characters. Expected: no crash, no cache file outside the cache dir, the layout shown as unavailable, switching still works. Tests: Task 6 (`LayoutIds::parse` rejects them), Task 7 (`Session` reports `ids: None`), Task 13 (cache paths stay inside the dir), Task 16 (engine marks the layout unavailable and still switches).
2. **The firmware reports a layer the layout doesn't have, or a layer has an empty title.** Example: layer 7 on a 3-layer layout. Expected: no panic; chips and legends fall back to "Layer N" / "L7"; switching still works by index. Tests: Task 12 (`→ L7` legend), Task 16 (unmapped layer 31), Task 17 (`layer_title` fallback).
3. **KEYDOWN/KEYUP at matrix positions that don't exist on the board, or KEYUP without KEYDOWN.** Examples: row 4 col 0, row 13. Expected: ignored silently. Tests: Task 11 (`oryx_index` → `None`), Task 17 (engine ignores them).
4. **Rapid flapping between transient and mapped layers.** Holding and releasing Navig quickly; one-shot layers firing repeatedly. Expected: at most one input-source switch per real change of mapped target, never the same source twice in a row. Test: Task 16 (`flapping_between_transient_and_mapped_layers_switches_once`).
5. **A hand-edited config with invalid parts.** Examples: layer keys `"abc"`, `"-1"`, `"300"`; empty source IDs; an unknown `appearance`; wrong value types; invalid TOML. Expected: Downlink starts using every valid part, logs a warning per invalid part, and keeps a corrupt file as `config.toml.bad-<unix-seconds>`. Tests: Task 15. Task 20 (`current_choice_resolves_installed_and_missing_sources`) covers a configured source that is no longer installed (shown as "⚠ … (not installed)").

```rust
//! Throwaway probe: pair with the Voyager over raw HID and print every packet.
use std::time::{Duration, Instant};

use hidapi::HidApi;

fn event_name(code: u8) -> &'static str {
    match code {
        0x00 => "FW_VERSION",
        0x03 => "PAIRING_FAILED",
        0x04 => "PAIRING_SUCCESS",
        0x05 => "LAYER",
        0x06 => "KEYDOWN",
        0x07 => "KEYUP",
        0xFE => "PROTOCOL_VERSION",
        0xFF => "ERROR",
        _ => "UNKNOWN",
    }
}

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let seconds: u64 = std::env::args()
        .nth(1)
        .and_then(|s| s.parse().ok())
        .unwrap_or(30);
    let api = HidApi::new()?;
    for d in api.device_list().filter(|d| d.vendor_id() == 0x3297) {
        eprintln!(
            "interface: pid={:#06x} usage_page={:#06x} usage={:#04x} serial={:?}",
            d.product_id(),
            d.usage_page(),
            d.usage(),
            d.serial_number()
        );
    }
    let info = api
        .device_list()
        .find(|d| {
            d.vendor_id() == 0x3297
                && d.product_id() == 0x1977
                && d.usage_page() == 0xFF60
                && d.usage() == 0x61
        })
        .ok_or("Voyager raw-HID interface (0xFF60/0x61) not found")?;
    let device = api.open_path(info.path())?;
    eprintln!("opened {:?} (shared build: {})", info.path(), cfg!(feature = "shared"));

    // hidapi wants a leading report-ID byte (0x00) before the 32-byte packet.
    let send = |code: u8| -> hidapi::HidResult<usize> {
        let mut report = [0u8; 33];
        report[1] = code;
        report[2] = 0xFE;
        device.write(&report)
    };
    send(0x00)?; // GET_FW_VERSION
    send(0xFE)?; // GET_PROTOCOL_VERSION
    send(0x01)?; // PAIRING_INIT

    let start = Instant::now();
    let mut buf = [0u8; 32];
    while start.elapsed() < Duration::from_secs(seconds) {
        let n = device.read_timeout(&mut buf, 100)?;
        if n == 0 {
            continue;
        }
        let hex: Vec<String> = buf[..n].iter().map(|b| format!("{b:02x}")).collect();
        println!(
            "{:.3}\t{}\t{}",
            start.elapsed().as_secs_f32(),
            event_name(buf[0]),
            hex.join(" ")
        );
    }
    Ok(())
}
```

```rust
//! Throwaway probe: list, read and select macOS keyboard input sources via TIS.
use std::ffi::c_void;
use std::time::Duration;

use core_foundation::base::TCFType;
use core_foundation::boolean::{CFBoolean, CFBooleanRef};
use core_foundation::string::{CFString, CFStringRef};
use core_foundation_sys::array::{CFArrayGetCount, CFArrayGetValueAtIndex, CFArrayRef};
use core_foundation_sys::base::{CFRelease, CFTypeRef};

type TISInputSourceRef = *const c_void;

#[link(name = "Carbon", kind = "framework")]
unsafe extern "C" {
    fn TISCreateInputSourceList(properties: *const c_void, include_all_installed: u8) -> CFArrayRef;
    fn TISCopyCurrentKeyboardInputSource() -> TISInputSourceRef;
    fn TISGetInputSourceProperty(source: TISInputSourceRef, key: CFStringRef) -> *const c_void;
    fn TISSelectInputSource(source: TISInputSourceRef) -> i32;
    static kTISPropertyInputSourceID: CFStringRef;
    static kTISPropertyLocalizedName: CFStringRef;
    static kTISPropertyInputSourceCategory: CFStringRef;
    static kTISPropertyInputSourceIsSelectCapable: CFStringRef;
    static kTISCategoryKeyboardInputSource: CFStringRef;
}

fn string_property(source: TISInputSourceRef, key: CFStringRef) -> Option<String> {
    let value = unsafe { TISGetInputSourceProperty(source, key) };
    (!value.is_null()).then(|| unsafe { CFString::wrap_under_get_rule(value as CFStringRef) }.to_string())
}

fn bool_property(source: TISInputSourceRef, key: CFStringRef) -> bool {
    let value = unsafe { TISGetInputSourceProperty(source, key) };
    !value.is_null() && bool::from(unsafe { CFBoolean::wrap_under_get_rule(value as CFBooleanRef) })
}

fn selectable_keyboard(source: TISInputSourceRef) -> bool {
    let keyboard = unsafe { CFString::wrap_under_get_rule(kTISCategoryKeyboardInputSource) }.to_string();
    string_property(source, unsafe { kTISPropertyInputSourceCategory }).as_deref() == Some(keyboard.as_str())
        && bool_property(source, unsafe { kTISPropertyInputSourceIsSelectCapable })
}

fn with_sources<T>(f: impl FnOnce(&[TISInputSourceRef]) -> T) -> T {
    let array = unsafe { TISCreateInputSourceList(std::ptr::null(), 0) };
    assert!(!array.is_null(), "TISCreateInputSourceList returned null");
    let count = unsafe { CFArrayGetCount(array) };
    let sources: Vec<TISInputSourceRef> =
        (0..count).map(|i| unsafe { CFArrayGetValueAtIndex(array, i) }).collect();
    let result = f(&sources);
    unsafe { CFRelease(array as CFTypeRef) };
    result
}

fn current() -> Option<String> {
    let source = unsafe { TISCopyCurrentKeyboardInputSource() };
    if source.is_null() {
        return None;
    }
    let id = string_property(source, unsafe { kTISPropertyInputSourceID });
    unsafe { CFRelease(source as CFTypeRef) };
    id
}

fn main() {
    let args: Vec<String> = std::env::args().skip(1).collect();
    match args.first().map(String::as_str) {
        Some("list") => with_sources(|sources| {
            for &s in sources.iter().filter(|s| selectable_keyboard(**s)) {
                println!(
                    "{}\t{}",
                    string_property(s, unsafe { kTISPropertyInputSourceID }).unwrap_or_default(),
                    string_property(s, unsafe { kTISPropertyLocalizedName }).unwrap_or_default()
                );
            }
        }),
        Some("current") => println!("{}", current().unwrap_or_default()),
        Some("select") if args.len() == 2 => {
            let id = &args[1];
            let status = with_sources(|sources| {
                sources
                    .iter()
                    .copied()
                    .find(|s| {
                        selectable_keyboard(*s)
                            && string_property(*s, unsafe { kTISPropertyInputSourceID }).as_deref()
                                == Some(id.as_str())
                    })
                    .map(|s| unsafe { TISSelectInputSource(s) })
            });
            std::thread::sleep(Duration::from_millis(200));
            println!("status={status:?} now={}", current().unwrap_or_default());
        }
        _ => eprintln!("usage: tis-probe list | current | select <input-source-id>"),
    }
}
```

```rust
//! Throwaway probe: an iced daemon that owns a tray-icon menu and on-demand windows.
use iced::futures::channel::mpsc;
use iced::futures::{SinkExt, Stream, StreamExt};
use iced::theme::Mode;
use iced::widget::{column, text};
use iced::{Element, Subscription, Task, system, window};
use tray_icon::menu::{Menu, MenuEvent, MenuItem, PredefinedMenuItem};
use tray_icon::{Icon, TrayIcon, TrayIconBuilder};

fn main() -> iced::Result {
    let result = iced::daemon(Probe::boot, Probe::update, Probe::view)
        .title(|_: &Probe, _: window::Id| "Tray probe".to_string())
        .subscription(Probe::subscription)
        .run();
    println!("event loop returned: {result:?}");
    result
}

struct Probe {
    tray: Option<TrayIcon>,
    windows: Vec<window::Id>,
    mode: Option<Mode>,
}

#[derive(Debug, Clone)]
enum Message {
    Init,
    Menu(String),
    Opened(window::Id),
    Closed(window::Id),
    Theme(Mode),
}

impl Probe {
    fn boot() -> (Self, Task<Message>) {
        (
            Self { tray: None, windows: Vec::new(), mode: None },
            Task::batch([Task::done(Message::Init), system::theme().map(Message::Theme)]),
        )
    }

    fn update(&mut self, message: Message) -> Task<Message> {
        match message {
            Message::Init => {
                hide_dock_icon();
                let menu = Menu::new();
                menu.append(&MenuItem::with_id("open", "Open window", true, None)).unwrap();
                menu.append(&PredefinedMenuItem::separator()).unwrap();
                menu.append(&MenuItem::with_id("quit", "Quit", true, None)).unwrap();
                let icon = Icon::from_rgba(dot_icon(36), 36, 36).unwrap();
                self.tray = Some(
                    TrayIconBuilder::new()
                        .with_icon(icon)
                        .with_icon_as_template(true)
                        .with_menu(Box::new(menu))
                        .with_tooltip("Tray probe")
                        .build()
                        .expect("tray icon"),
                );
                println!("tray created; on main thread: {}", objc2::MainThreadMarker::new().is_some());
                Task::none()
            }
            Message::Menu(id) if id == "open" => {
                let (id, open) = window::open(window::Settings::default());
                self.windows.push(id);
                activate_app();
                open.map(Message::Opened)
            }
            Message::Menu(id) if id == "quit" => {
                println!("quit via menu");
                iced::exit()
            }
            Message::Menu(other) => {
                println!("menu event: {other}");
                Task::none()
            }
            Message::Opened(id) => {
                println!("window opened: {id:?}");
                window::gain_focus(id)
            }
            Message::Closed(id) => {
                self.windows.retain(|w| *w != id);
                println!("window closed; {} left; daemon still running", self.windows.len());
                Task::none()
            }
            Message::Theme(mode) => {
                println!("system theme: {mode:?}");
                self.mode = Some(mode);
                Task::none()
            }
        }
    }

    fn view(&self, _id: window::Id) -> Element<'_, Message> {
        column![
            text(format!("System theme: {:?}", self.mode)),
            text("Close this window: the menu-bar icon must stay."),
        ]
        .spacing(10)
        .padding(20)
        .into()
    }

    fn subscription(&self) -> Subscription<Message> {
        Subscription::batch([
            Subscription::run(menu_events).map(Message::Menu),
            window::close_events().map(Message::Closed),
            system::theme_changes().map(Message::Theme),
        ])
    }
}

fn menu_events() -> impl Stream<Item = String> {
    iced::stream::channel(16, async |mut output: mpsc::Sender<String>| {
        let (tx, mut rx) = mpsc::unbounded::<String>();
        MenuEvent::set_event_handler(Some(move |event: MenuEvent| {
            let _ = tx.unbounded_send(event.id.0);
        }));
        while let Some(id) = rx.next().await {
            if output.send(id).await.is_err() {
                break;
            }
        }
    })
}

fn dot_icon(size: u32) -> Vec<u8> {
    let mut rgba = vec![0u8; (size * size * 4) as usize];
    let c = size as f32 / 2.0;
    for y in 0..size {
        for x in 0..size {
            let (dx, dy) = (x as f32 + 0.5 - c, y as f32 + 0.5 - c);
            if (dx * dx + dy * dy).sqrt() <= c * 0.6 {
                rgba[((y * size + x) * 4 + 3) as usize] = 255;
            }
        }
    }
    rgba
}
```

```rust
use crate::{PACKET_LEN, STOP};

/// A host → keyboard request.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Command {
    GetFwVersion,
    PairingInit,
    GetProtocolVersion,
    /// `on = false` turns `layer` off; `on = true` moves to `layer`.
    SetLayer { on: bool, layer: u8 },
}

impl Command {
    pub fn code(self) -> u8 {
        match self {
            Command::GetFwVersion => 0x00,
            Command::PairingInit => 0x01,
            Command::SetLayer { .. } => 0x04,
            Command::GetProtocolVersion => 0xFE,
        }
    }

    pub fn encode(self) -> [u8; PACKET_LEN] {
        let mut packet = [0u8; PACKET_LEN];
        packet[0] = self.code();
        let mut len = 1;
        if let Command::SetLayer { on, layer } = self {
            packet[1] = u8::from(on);
            packet[2] = layer;
            len = 3;
        }
        packet[len] = STOP;
        packet
    }
}
```

```rust
use crate::STOP;

/// A key's position in the firmware matrix, as reported by KEYDOWN/KEYUP.
#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash, PartialOrd, Ord)]
pub struct MatrixPos {
    pub row: u8,
    pub col: u8,
}

/// A keyboard → host message.
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Event {
    FwVersion(String),
    PairingSuccess,
    PairingFailed,
    Layer(u8),
    KeyDown(MatrixPos),
    KeyUp(MatrixPos),
    ProtocolVersion(u8),
    Error(u8),
    Unknown(u8),
}

#[derive(Debug, Clone, Copy, PartialEq, Eq, thiserror::Error)]
pub enum DecodeError {
    #[error("empty packet")]
    Empty,
    #[error("event 0x{code:02x} is truncated")]
    Truncated { code: u8 },
}

impl Event {
    pub fn decode(packet: &[u8]) -> Result<Event, DecodeError> {
        let (&code, params) = packet.split_first().ok_or(DecodeError::Empty)?;
        let param = |i: usize| params.get(i).copied().ok_or(DecodeError::Truncated { code });
        Ok(match code {
            0x00 => Event::FwVersion(text_until_stop(params)),
            0x03 => Event::PairingFailed,
            0x04 => Event::PairingSuccess,
            0x05 => Event::Layer(param(0)?),
            0x06 => Event::KeyDown(MatrixPos { col: param(0)?, row: param(1)? }),
            0x07 => Event::KeyUp(MatrixPos { col: param(0)?, row: param(1)? }),
            0xFE => Event::ProtocolVersion(param(0)?),
            0xFF => Event::Error(param(0)?),
            other => Event::Unknown(other),
        })
    }
}

fn text_until_stop(bytes: &[u8]) -> String {
    let end = bytes.iter().position(|&b| b == STOP || b == 0).unwrap_or(bytes.len());
    String::from_utf8_lossy(&bytes[..end]).into_owned()
}
```

```rust
use std::fmt;

const MAX_ID_LEN: usize = 32;

/// The Oryx layout and revision a keyboard runs, from its firmware version
/// string or USB serial number (`"layoutId/revisionId"`).
///
/// Both parts are 1–32 ASCII alphanumerics, so they are safe to use in file names.
#[derive(Debug, Clone, PartialEq, Eq, Hash)]
pub struct LayoutIds {
    layout_id: String,
    revision_id: String,
}

impl LayoutIds {
    pub fn new(layout_id: &str, revision_id: &str) -> Option<LayoutIds> {
        (is_valid_id(layout_id) && is_valid_id(revision_id)).then(|| LayoutIds {
            layout_id: layout_id.to_owned(),
            revision_id: revision_id.to_owned(),
        })
    }

    pub fn parse(text: &str) -> Option<LayoutIds> {
        let (layout_id, revision_id) = text.trim().split_once('/')?;
        LayoutIds::new(layout_id, revision_id)
    }

    pub fn layout_id(&self) -> &str {
        &self.layout_id
    }

    pub fn revision_id(&self) -> &str {
        &self.revision_id
    }
}

fn is_valid_id(part: &str) -> bool {
    !part.is_empty() && part.len() <= MAX_ID_LEN && part.bytes().all(|b| b.is_ascii_alphanumeric())
}

impl fmt::Display for LayoutIds {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        write!(f, "{}/{}", self.layout_id, self.revision_id)
    }
```

```rust
use std::time::{Duration, Instant};

use oryx_protocol::{Command, Event, LayoutIds, Model};

use crate::DeviceEvent;

/// How long to wait for `PAIRING_SUCCESS` before calling the firmware unsupported.
pub const HANDSHAKE_TIMEOUT: Duration = Duration::from_secs(2);

/// After this long without any packet, pair again. The firmware drops its
/// paired state whenever a send fails, for example while the host sleeps.
pub const HEARTBEAT_IDLE: Duration = Duration::from_secs(5);

pub const UNSUPPORTED_REASON: &str = "Firmware doesn't report live data";

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
enum Phase {
    Handshaking,
    Connected,
    Unsupported,
}

/// Handshake, heartbeat and event filtering for one open interface. No I/O:
/// callers feed packets and clock ticks in and send the returned commands.
#[derive(Debug)]
pub struct Session {
    model: Model,
    phase: Phase,
    started: Instant,
    last_rx: Instant,
    last_ping: Instant,
    ids: Option<LayoutIds>,
    protocol: Option<u8>,
    pending_layer: Option<u8>,
}

impl Session {
    pub fn start(model: Model, serial: Option<&str>, now: Instant) -> (Session, Vec<Command>) {
        let session = Session {
            model,
            phase: Phase::Handshaking,
            started: now,
            last_rx: now,
            last_ping: now,
            ids: serial.and_then(LayoutIds::parse),
            protocol: None,
            pending_layer: None,
        };
        // Replies arrive in this order, so the IDs are known before pairing completes.
        (session, vec![Command::GetFwVersion, Command::GetProtocolVersion, Command::PairingInit])
    }

    pub fn on_packet(&mut self, packet: &[u8], now: Instant) -> Vec<DeviceEvent> {
        self.last_rx = now;
        let event = match Event::decode(packet) {
            Ok(event) => event,
            Err(error) => {
                tracing::debug!(%error, "ignoring malformed packet");
                return Vec::new();
            }
        };
        match event {
            Event::FwVersion(version) => {
                match LayoutIds::parse(&version) {
                    Some(ids) => self.ids = Some(ids),
                    None => tracing::warn!(%version, "unrecognised firmware version string"),
                }
                Vec::new()
            }
            Event::ProtocolVersion(version) => {
                if !(4..=5).contains(&version) {
                    tracing::warn!(version, "untested Oryx protocol version; only core events are used");
                }
                self.protocol = Some(version);
                Vec::new()
            }
            Event::PairingSuccess => self.become_connected(),
            Event::Layer(layer) if self.phase == Phase::Connected => vec![DeviceEvent::Layer(layer)],
            Event::Layer(layer) => {
                self.pending_layer = Some(layer);
                Vec::new()
            }
            Event::KeyDown(pos) if self.phase == Phase::Connected => vec![DeviceEvent::KeyDown(pos)],
            Event::KeyUp(pos) if self.phase == Phase::Connected => vec![DeviceEvent::KeyUp(pos)],
            Event::Error(code) => {
                tracing::warn!(code, "keyboard reported an error");
                Vec::new()
            }
            other => {
                tracing::debug!(?other, "ignoring event");
                Vec::new()
            }
        }
    }

    pub fn on_tick(&mut self, now: Instant) -> (Vec<DeviceEvent>, Vec<Command>) {
        let mut events = Vec::new();
        let mut commands = Vec::new();
        if self.phase == Phase::Handshaking && now.duration_since(self.started) >= HANDSHAKE_TIMEOUT {
            self.phase = Phase::Unsupported;
            events.push(DeviceEvent::Unsupported { reason: UNSUPPORTED_REASON.into() });
        }
        if now.duration_since(self.last_rx) >= HEARTBEAT_IDLE
            && now.duration_since(self.last_ping) >= HEARTBEAT_IDLE
        {
            self.last_ping = now;
            commands.push(Command::PairingInit);
        }
        (events, commands)
    }

    fn become_connected(&mut self) -> Vec<DeviceEvent> {
        if self.phase == Phase::Connected {
            return Vec::new(); // a heartbeat's reply
        }
        self.phase = Phase::Connected;
        let mut events = vec![DeviceEvent::Connected {
            model: self.model,
            ids: self.ids.clone(),
            protocol: self.protocol,
        }];
        if let Some(layer) = self.pending_layer.take() {
            events.push(DeviceEvent::Layer(layer));
        }
        events
    }
}
```

```rust
use std::sync::mpsc::{Receiver, TryRecvError};
use std::thread::sleep;
use std::time::{Duration, Instant};

use oryx_protocol::{Command, PACKET_LEN};

use crate::{DeviceEvent, Discovery, Found, Session, Transport};

/// Requests from the app to the device thread.
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum DeviceCommand {
    Send(Command),
    Shutdown,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct Timing {
    pub poll_interval: Duration,
    pub read_timeout: Duration,
    pub backoff_start: Duration,
    pub backoff_max: Duration,
}

impl Default for Timing {
    fn default() -> Self {
        Timing {
            poll_interval: Duration::from_secs(1),
            read_timeout: Duration::from_millis(100),
            backoff_start: Duration::from_secs(1),
            backoff_max: Duration::from_secs(10),
        }
    }
}

enum Exit {
    Shutdown,
    Lost(String),
    ReceiverGone,
}

/// Finds, opens and drives the keyboard until shut down. Blocking: run it on
/// its own thread. Stops when `emit` returns `false`.
pub fn run<D: Discovery>(
    mut discovery: D,
    timing: Timing,
    commands: Receiver<DeviceCommand>,
    mut emit: impl FnMut(DeviceEvent) -> bool,
) {
    let mut backoff = timing.backoff_start;
    loop {
        if shutdown_requested(&commands) {
            return;
        }
        let found = match discovery.find() {
            Ok(Some(found)) => found,
            Ok(None) => {
                sleep(timing.poll_interval);
                continue;
            }
            Err(error) => {
                tracing::warn!(%error, "keyboard enumeration failed");
                sleep(timing.poll_interval);
                continue;
            }
        };
        let mut transport = match discovery.open(&found) {
            Ok(transport) => {
                backoff = timing.backoff_start;
                transport
            }
            Err(reason) => {
                tracing::warn!(%reason, "could not open the keyboard");
                if !emit(DeviceEvent::OpenFailed { reason }) {
                    return;
                }
                sleep(backoff);
                backoff = (backoff * 2).min(timing.backoff_max);
                continue;
            }
        };
        match drive(&mut transport, &found, &timing, &commands, &mut emit) {
            Exit::Shutdown | Exit::ReceiverGone => return,
            Exit::Lost(reason) => {
                if !emit(DeviceEvent::Disconnected { reason }) {
                    return;
                }
            }
        }
    }
}

fn shutdown_requested(commands: &Receiver<DeviceCommand>) -> bool {
    loop {
        match commands.try_recv() {
            Ok(DeviceCommand::Shutdown) | Err(TryRecvError::Disconnected) => return true,
            Ok(DeviceCommand::Send(command)) => {
                tracing::debug!(?command, "dropping command: no keyboard connected");
            }
            Err(TryRecvError::Empty) => return false,
        }
    }
}

fn drive<T: Transport>(
    transport: &mut T,
    found: &Found,
    timing: &Timing,
    commands: &Receiver<DeviceCommand>,
    emit: &mut impl FnMut(DeviceEvent) -> bool,
) -> Exit {
    let (mut session, hello) = Session::start(found.model, found.serial.as_deref(), Instant::now());
    for command in hello {
        if let Err(error) = transport.write(&command.encode()) {
            return Exit::Lost(error);
        }
    }
    let mut buf = [0u8; PACKET_LEN];
    loop {
        loop {
            match commands.try_recv() {
                Ok(DeviceCommand::Shutdown) | Err(TryRecvError::Disconnected) => return Exit::Shutdown,
                Ok(DeviceCommand::Send(command)) => {
                    if let Err(error) = transport.write(&command.encode()) {
                        return Exit::Lost(error);
                    }
                }
                Err(TryRecvError::Empty) => break,
            }
        }
        match transport.read(&mut buf, timing.read_timeout) {
            Ok(0) => {}
            Ok(n) => {
                for event in session.on_packet(&buf[..n.min(PACKET_LEN)], Instant::now()) {
                    if !emit(event) {
                        return Exit::ReceiverGone;
                    }
                }
            }
            Err(error) => return Exit::Lost(error),
        }
        let (events, to_send) = session.on_tick(Instant::now());
        for event in events {
            if !emit(event) {
                return Exit::ReceiverGone;
            }
        }
        for command in to_send {
            if let Err(error) = transport.write(&command.encode()) {
                return Exit::Lost(error);
            }
        }
    }
}
```

```rust
use std::time::Duration;

use hidapi::{HidApi, HidDevice};
use oryx_protocol::{Model, PACKET_LEN};

use crate::{Discovery, Found, Transport};

/// Finds supported keyboards through hidapi (IOKit on macOS, hidraw on Linux).
#[derive(Default)]
pub struct HidDiscovery {
    api: Option<HidApi>,
}

impl HidDiscovery {
    pub fn new() -> HidDiscovery {
        HidDiscovery::default()
    }
}

impl Discovery for HidDiscovery {
    type Transport = HidTransport;

    fn find(&mut self) -> Result<Option<Found>, String> {
        if self.api.is_none() {
            self.api = Some(HidApi::new().map_err(|e| e.to_string())?);
        }
        let api = self.api.as_mut().expect("initialised above");
        api.refresh_devices().map_err(|e| e.to_string())?;
        Ok(api.device_list().find_map(|info| {
            let model = Model::from_interface(info.vendor_id(), info.product_id(), info.usage_page(), info.usage())?;
            Some(Found {
                model,
                serial: info.serial_number().map(str::to_owned),
                path: info.path().to_string_lossy().into_owned(),
            })
        }))
    }

    fn open(&mut self, found: &Found) -> Result<HidTransport, String> {
        let api = self.api.as_ref().ok_or_else(|| "HID API not initialised".to_owned())?;
        let path = CString::new(found.path.clone()).map_err(|e| e.to_string())?;
        let device = api.open_path(&path).map_err(|e| e.to_string())?;
        Ok(HidTransport { device })
    }
}

pub struct HidTransport {
    device: HidDevice,
}

impl Transport for HidTransport {
    fn read(&mut self, buf: &mut [u8; PACKET_LEN], timeout: Duration) -> Result<usize, String> {
        let millis = i32::try_from(timeout.as_millis()).unwrap_or(i32::MAX);
        self.device.read_timeout(buf, millis).map_err(|e| e.to_string())
    }

    fn write(&mut self, packet: &[u8; PACKET_LEN]) -> Result<(), String> {
        // hidapi expects a leading report-ID byte (0x00: no numbered reports).
        let mut report = [0u8; PACKET_LEN + 1];
        report[1..].copy_from_slice(packet);
        self.device.write(&report).map(|_| ()).map_err(|e| e.to_string())
    }
}
```

```rust
/// Parses the raw JSON body returned by Oryx's `getLayout` GraphQL query.
pub fn parse_graphql(json: &str) -> Result<Layout, ParseError> {
    let response: RawResponse = serde_json::from_str(json).map_err(|e| ParseError::Json(e.to_string()))?;
    let Some(raw) = response.data.and_then(|data| data.layout) else {
        return Err(match response.errors.into_iter().next() {
            Some(error) => ParseError::Api(error.message),
            None => ParseError::NotFound,
        });
    };
    let mut layers: Vec<Layer> = raw.revision.layers.into_iter().map(RawLayer::into_layer).collect();
    layers.sort_by_key(|layer| layer.index);
    Ok(Layout {
        title: raw.title.unwrap_or_default(),
        layout_id: raw.hash_id,
        revision_id: raw.revision.hash_id,
        geometry: raw.geometry.unwrap_or_default(),
        layers,
    })
}
```

```rust
//! Turns key actions into short display legends.

use crate::{Action, Key, Modifiers};

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum ModifierStyle {
    /// ⌃ ⌥ ⇧ ⌘ (macOS).
    Symbols,
    /// Ctrl Alt Shift Super (Linux).
    Words,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum LegendKind {
    Normal,
    /// The tap action switches layers; drawn with the accent border.
    Layer,
    /// Falls through to the layer below.
    Transparent,
    /// Does nothing (`KC_NO`).
    Blank,
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct KeyLegend {
    pub tap: String,
    pub hold: Option<String>,
    pub kind: LegendKind,
}

const LAYER_CODES: [&str; 7] = ["TO", "DF", "TG", "OSL", "MO", "TT", "LM"];

pub fn key_legend(key: &Key, layer_titles: &[String], style: ModifierStyle) -> KeyLegend {
    if key.is_transparent() {
        return KeyLegend { tap: "▽".into(), hold: None, kind: LegendKind::Transparent };
    }
    let hold = key.hold.as_ref().map(|action| hold_label(action, layer_titles, style));
    let (tap, kind) = match (key.custom_label.as_deref(), key.tap.as_ref()) {
        (Some(label), tap) => {
            let kind = if tap.is_some_and(is_layer_action) { LegendKind::Layer } else { LegendKind::Normal };
            (label.to_owned(), kind)
        }
        (None, Some(action)) => tap_label(action, layer_titles, style),
        (None, None) => (String::new(), LegendKind::Normal),
    };
    let kind = if tap.is_empty() && hold.is_none() { LegendKind::Blank } else { kind };
    KeyLegend { tap, hold, kind }
}

fn is_layer_action(action: &Action) -> bool {
    action.layer.is_some() && LAYER_CODES.contains(&action.code.as_str())
}

fn tap_label(action: &Action, titles: &[String], style: ModifierStyle) -> (String, LegendKind) {
    if let Some(layer) = action.layer.filter(|_| is_layer_action(action)) {
        let title = layer_title(titles, layer);
        let text = match action.code.as_str() {
            "TO" | "DF" => format!("→ {title}"),
            "TG" => format!("⇆ {title}"),
            "OSL" => format!("1× {title}"),
            _ => title,
        };
        return (text, LegendKind::Layer);
    }
    (with_modifiers(&code_label(&action.code, style), action.modifiers, style), LegendKind::Normal)
}

fn hold_label(action: &Action, titles: &[String], style: ModifierStyle) -> String {
    match action.layer {
        Some(layer) if is_layer_action(action) => layer_title(titles, layer),
        _ => with_modifiers(&code_label(&action.code, style), action.modifiers, style),
    }
}

fn layer_title(titles: &[String], layer: u8) -> String {
    titles
        .get(usize::from(layer))
        .map(|title| title.trim())
        .filter(|title| !title.is_empty())
        .map(str::to_owned)
        .unwrap_or_else(|| format!("L{layer}"))
}

fn with_modifiers(label: &str, m: Modifiers, style: ModifierStyle) -> String {
    if !m.any() {
        return label.to_owned();
    }
    let parts = [(m.ctrl, "⌃", "Ctrl"), (m.alt, "⌥", "Alt"), (m.shift, "⇧", "Shift"), (m.gui, "⌘", "Super")];
    match style {
        ModifierStyle::Symbols => {
            let prefix: String = parts.iter().filter(|p| p.0).map(|p| p.1).collect();
            format!("{prefix}{label}")
        }
        ModifierStyle::Words => {
            let prefix: Vec<&str> = parts.iter().filter(|p| p.0).map(|p| p.2).collect();
            format!("{}+{label}", prefix.join("+"))
        }
    }
}

/// A short legend for a keycode.
pub fn code_label(code: &str, style: ModifierStyle) -> String {
    if let Some(label) = builtin(code, style) {
        return label.to_owned();
    }
    let bare = code.strip_prefix("KC_").unwrap_or(code);
    if let Some(rest) = bare.strip_prefix("KP_")
        && rest.chars().count() == 1
    {
        return rest.to_owned();
    }
    if bare.chars().count() == 1 || is_function_key(bare) {
        return bare.to_owned();
    }
    bare.replace('_', " ")
}

fn is_function_key(name: &str) -> bool {
    name.strip_prefix('F').is_some_and(|n| !n.is_empty() && n.chars().all(|c| c.is_ascii_digit()))
}

fn sym(style: ModifierStyle, symbol: &'static str, word: &'static str) -> &'static str {
    match style {
        ModifierStyle::Symbols => symbol,
        ModifierStyle::Words => word,
    }
}
```

```rust
/// Serves exactly one HTTP response and returns the raw request it received.
fn serve_once(status_line: &'static str, body: &'static str) -> (String, JoinHandle<String>) {
    let listener = TcpListener::bind("127.0.0.1:0").unwrap();
    let url = format!("http://{}/graphql", listener.local_addr().unwrap());
    let handle = std::thread::spawn(move || {
        let (mut stream, _) = listener.accept().unwrap();
        let mut request = Vec::new();
        let mut buf = [0u8; 4096];
        while !request_complete(&request) {
            let n = stream.read(&mut buf).unwrap();
            if n == 0 {
                break;
            }
            request.extend_from_slice(&buf[..n]);
        }
        let response = format!(
            "{status_line}\r\nContent-Type: application/json\r\nContent-Length: {}\r\nConnection: close\r\n\r\n{body}",
            body.len()
        );
        stream.write_all(response.as_bytes()).unwrap();
        String::from_utf8_lossy(&request).into_owned()
    });
    (url, handle)
}

fn request_complete(raw: &[u8]) -> bool {
    let text = String::from_utf8_lossy(raw);
    let Some(header_end) = text.find("\r\n\r\n") else { return false };
    let length = text[..header_end]
        .lines()
        .find_map(|line| {
            let (name, value) = line.split_once(':')?;
            name.trim().eq_ignore_ascii_case("content-length").then(|| value.trim().parse::<usize>().ok())?
        })
        .unwrap_or(0);
    raw.len() >= header_end + 4 + length
}
```

```rust
use std::path::PathBuf;
use std::time::SystemTime;
use std::{fs, io};

use oryx_protocol::LayoutIds;

/// Raw Oryx JSON, one file per layout revision. It is parsed on load, so a
/// model change never invalidates the cache.
#[derive(Debug, Clone)]
pub struct LayoutCache {
    dir: PathBuf,
}

impl LayoutCache {
    pub fn new(dir: impl Into<PathBuf>) -> LayoutCache {
        LayoutCache { dir: dir.into() }
    }

    /// `LayoutIds` only holds ASCII alphanumerics, so this never leaves `dir`.
    pub fn path_for(&self, ids: &LayoutIds) -> PathBuf {
        self.dir.join(format!("{}-{}.json", ids.layout_id(), ids.revision_id()))
    }

    pub fn load(&self, ids: &LayoutIds) -> Option<String> {
        fs::read_to_string(self.path_for(ids)).ok()
    }

    pub fn store(&self, ids: &LayoutIds, json: &str) -> io::Result<()> {
        fs::create_dir_all(&self.dir)?;
        let path = self.path_for(ids);
        let tmp = path.with_extension("json.tmp");
        fs::write(&tmp, json)?;
        fs::rename(&tmp, &path)
    }

    pub fn modified(&self, ids: &LayoutIds) -> Option<SystemTime> {
        fs::metadata(self.path_for(ids)).ok()?.modified().ok()
    }
}
```

```rust
//! Fetches a layout revision from Oryx's GraphQL API.

use std::time::Duration;

use oryx_protocol::LayoutIds;
use serde_json::{Value, json};

pub use reqwest::Client as HttpClient;

pub const ORYX_GRAPHQL_URL: &str = "https://oryx.zsa.io/graphql";
pub const REQUEST_TIMEOUT: Duration = Duration::from_secs(15);

const QUERY: &str = "query getLayout($hashId: String!, $revisionId: String!, $geometry: String) { \
layout(hashId: $hashId, geometry: $geometry, revisionId: $revisionId) { \
title geometry hashId revision { hashId layers { position title keys } } } }";

#[derive(Debug, thiserror::Error)]
pub enum FetchError {
    #[error("network error: {0}")]
    Network(#[from] reqwest::Error),
    #[error("Oryx returned HTTP {0}")]
    Status(u16),
}

pub fn user_agent(version: &str) -> String {
    format!("Downlink/{version} (+https://github.com/zayatura/downlink)")
}

pub fn client_builder(version: &str) -> reqwest::ClientBuilder {
    reqwest::Client::builder().user_agent(user_agent(version)).timeout(REQUEST_TIMEOUT)
}

pub fn request_body(ids: &LayoutIds, geometry: &str) -> Value {
    json!({
        "operationName": "getLayout",
        "query": QUERY,
        "variables": {"hashId": ids.layout_id(), "revisionId": ids.revision_id(), "geometry": geometry},
    })
}

/// Returns the raw JSON body; parse it with [`crate::parse_graphql`].
pub async fn fetch_layout(client: &HttpClient, url: &str, ids: &LayoutIds, geometry: &str) -> Result<String, FetchError> {
    let response = client.post(url).json(&request_body(ids, geometry)).send().await?;
    let status = response.status();
    if !status.is_success() {
        return Err(FetchError::Status(status.as_u16()));
    }
    Ok(response.text().await?)
}
```

```rust
use core_foundation::base::TCFType;

use core_foundation::string::{CFString, CFStringRef};

use crate::{InputSource, InputSourceBackend, InputSourceError};

type TISInputSourceRef = *const c_void;

#[link(name = "Carbon", kind = "framework")]
unsafe extern "C" {
    fn TISCreateInputSourceList(properties: *const c_void, include_all_installed: u8) -> CFArrayRef;
    fn TISCopyCurrentKeyboardInputSource() -> TISInputSourceRef;
    fn TISGetInputSourceProperty(source: TISInputSourceRef, key: CFStringRef) -> *const c_void;
    fn TISSelectInputSource(source: TISInputSourceRef) -> i32;
    static kTISPropertyInputSourceID: CFStringRef;
    static kTISPropertyLocalizedName: CFStringRef;
    static kTISPropertyInputSourceCategory: CFStringRef;
    static kTISPropertyInputSourceIsSelectCapable: CFStringRef;
    static kTISCategoryKeyboardInputSource: CFStringRef;
}

pub struct TisBackend;

/// The enabled input sources; the CFArray is released on drop.
struct SourceList(CFArrayRef);

impl SourceList {
    fn enabled() -> Result<SourceList, InputSourceError> {
        // A null properties dictionary means "no filter"; 0 = enabled sources only.
        let array = unsafe { TISCreateInputSourceList(std::ptr::null(), 0) };
        if array.is_null() {
            Err(InputSourceError::Platform("TISCreateInputSourceList returned no list".into()))
        } else {
            Ok(SourceList(array))
        }
    }

    fn iter(&self) -> impl Iterator<Item = TISInputSourceRef> + '_ {
        let count = unsafe { CFArrayGetCount(self.0) };
        (0..count).map(move |i| unsafe { CFArrayGetValueAtIndex(self.0, i) })
    }
}

impl Drop for SourceList {
    fn drop(&mut self) {
        unsafe { CFRelease(self.0 as CFTypeRef) }
    }
}

fn string_property(source: TISInputSourceRef, key: CFStringRef) -> Option<String> {
    let value = unsafe { TISGetInputSourceProperty(source, key) };
    (!value.is_null()).then(|| unsafe { CFString::wrap_under_get_rule(value as CFStringRef) }.to_string())
}

fn bool_property(source: TISInputSourceRef, key: CFStringRef) -> bool {
    let value = unsafe { TISGetInputSourceProperty(source, key) };
    !value.is_null() && bool::from(unsafe { CFBoolean::wrap_under_get_rule(value as CFBooleanRef) })
}

fn source_id(source: TISInputSourceRef) -> Option<String> {
    string_property(source, unsafe { kTISPropertyInputSourceID })
}

fn is_selectable_keyboard(source: TISInputSourceRef) -> bool {
    let keyboard = unsafe { CFString::wrap_under_get_rule(kTISCategoryKeyboardInputSource) }.to_string();
    string_property(source, unsafe { kTISPropertyInputSourceCategory }).as_deref() == Some(keyboard.as_str())
        && bool_property(source, unsafe { kTISPropertyInputSourceIsSelectCapable })
}

impl InputSourceBackend for TisBackend {
    fn list(&self) -> Result<Vec<InputSource>, InputSourceError> {
        let list = SourceList::enabled()?;
        let mut sources: Vec<InputSource> = list
            .iter()
            .filter(|source| is_selectable_keyboard(*source))
            .filter_map(|source| {
                let id = source_id(source)?;
                let name = string_property(source, unsafe { kTISPropertyLocalizedName }).unwrap_or_else(|| id.clone());
                Some(InputSource { id, name })
            })
            .collect();
        sources.sort_by(|a, b| a.name.cmp(&b.name).then_with(|| a.id.cmp(&b.id)));
        sources.dedup_by(|a, b| a.id == b.id);
        Ok(sources)
    }

    fn current(&self) -> Result<String, InputSourceError> {
        let source = unsafe { TISCopyCurrentKeyboardInputSource() };
        if source.is_null() {
            return Err(InputSourceError::Platform("no current keyboard input source".into()));
        }
        let id = source_id(source);
        unsafe { CFRelease(source as CFTypeRef) };
        id.ok_or_else(|| InputSourceError::Platform("the current input source has no ID".into()))
    }

    fn select(&self, id: &str) -> Result<(), InputSourceError> {
        let list = SourceList::enabled()?;
        let source = list
            .iter()
            .find(|source| is_selectable_keyboard(*source) && source_id(*source).as_deref() == Some(id))
            .ok_or_else(|| InputSourceError::NotFound(id.to_owned()))?;
        let status = unsafe { TISSelectInputSource(source) };
        if status == 0 {
            Ok(())
        } else {
            Err(InputSourceError::Platform(format!("TISSelectInputSource failed with status {status}")))
        }
    }
}
```

```rust
//! The settings file, `config.toml` (spec §7). Parsing is lenient: every
//! invalid part is skipped with a warning and the valid parts are kept.

use std::collections::BTreeMap;
use std::path::{Path, PathBuf};
use std::time::{SystemTime, UNIX_EPOCH};
use std::{fs, io};

use toml::{Table, Value};

#[derive(Debug, Clone, Copy, PartialEq, Eq, Default)]
pub enum Appearance {
    #[default]
    System,
    Light,
    Dark,
}

impl Appearance {
    pub fn as_str(self) -> &'static str {
        match self {
            Appearance::System => "system",
            Appearance::Light => "light",
            Appearance::Dark => "dark",
        }
    }

    fn from_name(name: &str) -> Option<Appearance> {
        match name {
            "system" => Some(Appearance::System),
            "light" => Some(Appearance::Light),
            "dark" => Some(Appearance::Dark),
            _ => None,
        }
    }
}

#[derive(Debug, Clone, PartialEq, Eq, Default)]
pub struct Config {
    pub appearance: Appearance,
    pub launch_at_login: bool,
    /// Input source to select on disconnect and quit; `None` = no change.
    pub fallback: Option<String>,
    /// Layer index → input-source ID. Layers not listed are transient.
    pub layers: BTreeMap<u8, String>,
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Loaded {
    pub config: Config,
    pub warnings: Vec<String>,
}

pub fn load(path: &Path) -> Loaded {
    let text = match fs::read_to_string(path) {
        Ok(text) => text,
        Err(error) if error.kind() == io::ErrorKind::NotFound => {
            return Loaded { config: Config::default(), warnings: Vec::new() };
        }
        Err(error) => {
            return Loaded {
                config: Config::default(),
                warnings: vec![format!("could not read {}: {error}; using defaults", path.display())],
            };
        }
    };
    match parse(&text) {
        Ok((config, warnings)) => Loaded { config, warnings },
        Err(error) => {
            let backup = backup_path(path, SystemTime::now());
            let note = match fs::rename(path, &backup) {
                Ok(()) => format!("kept the unreadable file as {}", backup.display()),
                Err(rename_error) => format!("could not move it aside: {rename_error}"),
            };
            Loaded {
                config: Config::default(),
                warnings: vec![format!("{} is not valid TOML ({error}); using defaults and {note}", path.display())],
            }
        }
    }
}

pub fn save(path: &Path, config: &Config) -> io::Result<()> {
    if let Some(dir) = path.parent() {
        fs::create_dir_all(dir)?;
    }
    let tmp = path.with_extension("toml.tmp");
    fs::write(&tmp, to_toml(config))?;
    fs::rename(&tmp, path)
}

pub fn backup_path(path: &Path, now: SystemTime) -> PathBuf {
    let secs = now.duration_since(UNIX_EPOCH).map(|d| d.as_secs()).unwrap_or(0);
    let name = path.file_name().map(|n| n.to_string_lossy().into_owned()).unwrap_or_else(|| "config.toml".into());
    path.with_file_name(format!("{name}.bad-{secs}"))
}

/// Returns the config plus one warning per ignored part. Errs only on invalid TOML.
pub fn parse(text: &str) -> Result<(Config, Vec<String>), String> {
    let table: Table = text.parse().map_err(|e: toml::de::Error| e.to_string())?;
    let mut config = Config::default();
    let mut warnings = Vec::new();
    match table.get("appearance") {
        None => {}
        Some(Value::String(name)) => match Appearance::from_name(name) {
            Some(appearance) => config.appearance = appearance,
            None => warnings.push(format!("unknown appearance {name:?}; using \"system\"")),
        },
        Some(other) => warnings.push(format!("appearance must be a string, found {}", other.type_str())),
    }
    match table.get("launch_at_login") {
        None => {}
        Some(Value::Boolean(enabled)) => config.launch_at_login = *enabled,
        Some(other) => warnings.push(format!("launch_at_login must be true or false, found {}", other.type_str())),
    }
    match table.get("switching") {
        None => {}
        Some(Value::Table(switching)) => read_switching(switching, &mut config, &mut warnings),
        Some(other) => warnings.push(format!("[switching] must be a table, found {}", other.type_str())),
    }
    Ok((config, warnings))
}

fn read_switching(switching: &Table, config: &mut Config, warnings: &mut Vec<String>) {
    match switching.get("fallback") {
        None => {}
        Some(Value::String(id)) => config.fallback = Some(id.trim().to_owned()).filter(|id| !id.is_empty()),
        Some(other) => warnings.push(format!("switching.fallback must be a string, found {}", other.type_str())),
    }
    match switching.get("layers") {
        None => {}
        Some(Value::Table(layers)) => {
            for (key, value) in layers {
                let Ok(index) = key.trim().parse::<u8>() else {
                    warnings.push(format!("ignoring [switching.layers] entry {key:?}: not a layer number 0-255"));
                    continue;
                };
                match value.as_str().map(str::trim) {
                    Some(id) if !id.is_empty() => {
                        config.layers.insert(index, id.to_owned());
                    }
                    _ => warnings.push(format!(
                        "ignoring [switching.layers] entry {key:?}: the value must be a non-empty input-source ID"
                    )),
                }
            }
        }
        Some(other) => warnings.push(format!("[switching.layers] must be a table, found {}", other.type_str())),
    }
}

pub fn to_toml(config: &Config) -> String {
    let mut switching = Table::new();
    if let Some(id) = &config.fallback {
        switching.insert("fallback".into(), Value::String(id.clone()));
    }
    let layers: Table = config.layers.iter().map(|(index, id)| (index.to_string(), Value::String(id.clone()))).collect();
    switching.insert("layers".into(), Value::Table(layers));
    let mut root = Table::new();
    root.insert("appearance".into(), Value::String(config.appearance.as_str().into()));
    root.insert("launch_at_login".into(), Value::Boolean(config.launch_at_login));
    root.insert("switching".into(), Value::Table(switching));
    root.to_string()
}
```

```rust
//! The pure state machine at the heart of Downlink: inputs in, effects out.

use std::sync::Arc;

use oryx_device::DeviceEvent;
use oryx_layout::Layout;
use oryx_protocol::{LayoutIds, Model};

use crate::config::Config;

#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Connection {
    Searching,
    Connected { model: Model, ids: Option<LayoutIds>, protocol: Option<u8> },
    Unsupported { reason: String },
    OpenFailed { reason: String },
}

#[derive(Debug, Clone, PartialEq)]
pub enum LayoutState {
    None,
    Loading,
    Ready(Arc<Layout>),
    Unavailable(String),
}

#[derive(Debug, Clone)]
pub enum Input {
    Device(DeviceEvent),
    LayoutLoaded { ids: LayoutIds, result: Result<Arc<Layout>, String> },
    CurrentSourceChanged(Option<String>),
    /// Selecting this source failed; allow retrying it on the next layer change.
    SelectFailed(String),
    ConfigChanged(Config),
    SetPaused(bool),
    RefreshLayout,
    Quit,
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Effect {
    SelectInputSource(String),
    /// Load the layout: from the cache first unless `force`, otherwise from Oryx.
    FetchLayout { model: Model, ids: LayoutIds, force: bool },
    PersistConfig,
    RefreshTray,
    Exit,
}

pub struct Engine {
    config: Config,
    connection: Connection,
    layer: Option<u8>,
    /// Last source *Downlink* selected (spec §6.4 rule 5).
    last_selected: Option<String>,
    paused: bool,
    layout: LayoutState,
    current_source: Option<String>,
}

impl Engine {
    pub fn new(config: Config) -> Engine {
        Engine {
            config,
            connection: Connection::Searching,
            layer: None,
            last_selected: None,
            paused: false,
            layout: LayoutState::None,
            current_source: None,
        }
    }

    pub fn config(&self) -> &Config {
        &self.config
    }

    pub fn connection(&self) -> &Connection {
        &self.connection
    }

    pub fn active_layer(&self) -> Option<u8> {
        self.layer
    }

    pub fn paused(&self) -> bool {
        self.paused
    }

    pub fn layout(&self) -> &LayoutState {
        &self.layout
    }

    pub fn current_source(&self) -> Option<&str> {
        self.current_source.as_deref()
    }

    pub fn handle(&mut self, input: Input) -> Vec<Effect> {
        match input {
            Input::Device(event) => self.on_device(event),
            Input::LayoutLoaded { ids, result } => self.on_layout_loaded(ids, result),
            Input::CurrentSourceChanged(id) => {
                if self.current_source == id {
                    return Vec::new();
                }
                self.current_source = id;
                vec![Effect::RefreshTray]
            }
            Input::SelectFailed(id) => {
                if self.last_selected.as_deref() == Some(id.as_str()) {
                    self.last_selected = None;
                }
                Vec::new()
            }
            Input::ConfigChanged(config) => {
                let mapping_changed = config.layers != self.config.layers;
                self.config = config;
                let mut effects = vec![Effect::PersistConfig, Effect::RefreshTray];
                if mapping_changed {
                    effects.extend(self.apply_layer_rule());
                }
                effects
            }
            Input::SetPaused(paused) => {
                self.paused = paused;
                vec![Effect::RefreshTray]
            }
            Input::RefreshLayout => match &self.connection {
                Connection::Connected { model, ids: Some(ids), .. } => {
                    let effects = vec![Effect::FetchLayout { model: *model, ids: ids.clone(), force: true }];
                    self.layout = LayoutState::Loading;
                    effects
                }
                _ => Vec::new(),
            },
            Input::Quit => {
                let mut effects = self.fallback_effect();
                effects.push(Effect::Exit);
                effects
            }
        }
    }

    fn on_device(&mut self, event: DeviceEvent) -> Vec<Effect> {
        match event {
            DeviceEvent::Connected { model, ids, protocol } => self.on_connected(model, ids, protocol),
            DeviceEvent::Layer(layer) => {
                if self.layer == Some(layer) {
                    return Vec::new();
                }
                self.layer = Some(layer);
                let mut effects = self.apply_layer_rule();
                effects.push(Effect::RefreshTray);
                effects
            }
            // Pressed-key tracking is added in Task 17.
            DeviceEvent::KeyDown(_) | DeviceEvent::KeyUp(_) => Vec::new(),
            DeviceEvent::Disconnected { reason } => {
                tracing::info!(%reason, "keyboard disconnected");
                self.lose_connection(Connection::Searching)
            }
            DeviceEvent::Unsupported { reason } => self.lose_connection(Connection::Unsupported { reason }),
            DeviceEvent::OpenFailed { reason } => self.lose_connection(Connection::OpenFailed { reason }),
        }
    }

    fn on_connected(&mut self, model: Model, ids: Option<LayoutIds>, protocol: Option<u8>) -> Vec<Effect> {
        self.connection = Connection::Connected { model, ids: ids.clone(), protocol };
        self.layer = None;
        let mut effects = vec![Effect::RefreshTray];
        match ids {
            Some(ids) => {
                let have_it = matches!(&self.layout, LayoutState::Ready(layout)
                    if layout.layout_id == ids.layout_id() && layout.revision_id == ids.revision_id());
                if !have_it {
                    self.layout = LayoutState::Loading;
                    effects.push(Effect::FetchLayout { model, ids, force: false });
                }
            }
            None => {
                self.layout = LayoutState::Unavailable("the keyboard didn't report which layout it runs".into());
            }
        }
        effects
    }

    /// Spec §6.4 rule 2: the fallback fires only on a transition.
    fn lose_connection(&mut self, next: Connection) -> Vec<Effect> {
        let was_connected = matches!(self.connection, Connection::Connected { .. });
        let newly_unsupported =
            matches!(next, Connection::Unsupported { .. }) && !matches!(self.connection, Connection::Unsupported { .. });
        let changed = self.connection != next;
        self.connection = next;
        self.layer = None;
        let mut effects = if changed { vec![Effect::RefreshTray] } else { Vec::new() };
        if was_connected || newly_unsupported {
            self.last_selected = None;
            effects.extend(self.fallback_effect());
        }
        effects
    }

    fn fallback_effect(&self) -> Vec<Effect> {
        if self.paused {
            return Vec::new();
        }
        self.config.fallback.clone().map(Effect::SelectInputSource).into_iter().collect()
    }

    /// Spec §6.4 rule 1.
    fn apply_layer_rule(&mut self) -> Vec<Effect> {
        if self.paused {
            return Vec::new();
        }
        let Some(layer) = self.layer else { return Vec::new() };
        let Some(target) = self.config.layers.get(&layer) else {
            return Vec::new(); // transient layer
        };
        if self.last_selected.as_deref() == Some(target.as_str()) {
            return Vec::new();
        }
        self.last_selected = Some(target.clone());
        vec![Effect::SelectInputSource(target.clone())]
    }

    fn on_layout_loaded(&mut self, ids: LayoutIds, result: Result<Arc<Layout>, String>) -> Vec<Effect> {
        if !matches!(self.layout, LayoutState::Loading) {
            return Vec::new();
        }
        if let Connection::Connected { ids: Some(current), .. } = &self.connection
            && current != &ids
        {
            return Vec::new();
        }
        self.layout = match result {
            Ok(layout) => LayoutState::Ready(layout),
            Err(error) => LayoutState::Unavailable(error),
        };
        vec![Effect::RefreshTray]
    }
}
```

```rust
        } else {
            String::new()
        };
        TrayView { connected, status, detail, paused: self.paused() }
    }
```

```rust
use std::path::{Path, PathBuf};

/// Where Downlink keeps its files (spec §7).
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Paths {
    pub config_file: PathBuf,
    pub cache_dir: PathBuf,
    pub log_dir: PathBuf,
    pub lock_file: PathBuf,
}

impl Paths {
    pub fn macos(home: &Path) -> Paths {
        let library = home.join("Library");
        let cache_dir = library.join("Caches/Downlink");
        Paths {
            config_file: library.join("Application Support/Downlink/config.toml"),
            lock_file: cache_dir.join("downlink.lock"),
            cache_dir,
            log_dir: library.join("Logs/Downlink"),
        }
    }

    pub fn xdg(config: &Path, cache: &Path, state: &Path, runtime: Option<&Path>) -> Paths {
        let cache_dir = cache.join("downlink");
        Paths {
            config_file: config.join("downlink/config.toml"),
            lock_file: runtime.map(|dir| dir.join("downlink.lock")).unwrap_or_else(|| cache_dir.join("downlink.lock")),
            cache_dir,
            log_dir: state.join("downlink"),
        }
    }

    pub fn detect() -> Option<Paths> {
        if cfg!(target_os = "macos") {
            Some(Paths::macos(&dirs::home_dir()?))
        } else {
            let state = dirs::state_dir().or_else(dirs::data_local_dir)?;
            Some(Paths::xdg(&dirs::config_dir()?, &dirs::cache_dir()?, &state, dirs::runtime_dir().as_deref()))
        }
    }

    pub fn layout_cache_dir(&self) -> PathBuf {
        self.cache_dir.join("layouts")
    }
}
```

```rust
use std::fs::{File, OpenOptions, TryLockError};
use std::io;
use std::path::Path;

/// Held for the life of the process; the OS releases it if the process dies.
pub struct InstanceLock {
    _file: File,
}

/// `Ok(None)` means another Downlink already holds the lock.
pub fn acquire(path: &Path) -> io::Result<Option<InstanceLock>> {
    if let Some(dir) = path.parent() {
        std::fs::create_dir_all(dir)?;
    }
    let file = OpenOptions::new().create(true).truncate(false).write(true).open(path)?;
    match file.try_lock() {
        Ok(()) => Ok(Some(InstanceLock { _file: file })),
        Err(TryLockError::WouldBlock) => Ok(None),
        Err(TryLockError::Error(error)) => Err(error),
    }
}
```

```rust
/// Overridable with the `DOWNLINK_LOG` environment variable (EnvFilter syntax).
pub const DEFAULT_FILTER: &str = "info,wgpu_core=warn,wgpu_hal=warn,naga=warn,iced_wgpu=warn,cosmic_text=warn";

/// Logs to daily-rotated files in `log_dir` (7 kept) and to stderr. Keep the guard alive.
pub fn init(log_dir: &Path) -> Option<WorkerGuard> {
    let filter = EnvFilter::try_from_env("DOWNLINK_LOG").unwrap_or_else(|_| EnvFilter::new(DEFAULT_FILTER));
    let appender = std::fs::create_dir_all(log_dir)
        .map_err(|e| e.to_string())
        .and_then(|()| {
            Builder::new()
                .rotation(Rotation::DAILY)
                .filename_prefix("downlink")
                .filename_suffix("log")
                .max_log_files(7)
                .build(log_dir)
                .map_err(|e| e.to_string())
        });
    let (file_layer, guard) = match appender {
        Ok(appender) => {
            let (writer, guard) = tracing_appender::non_blocking(appender);
            (Some(fmt::layer().with_ansi(false).with_writer(writer)), Some(guard))
        }
        Err(error) => {
            eprintln!("Downlink: file logging disabled ({error})");
            (None, None)
        }
    };
    tracing_subscriber::registry()
        .with(filter)
        .with(file_layer)
        .with(fmt::layer().with_writer(std::io::stderr))
        .init();
    guard
}
```

```rust
//! Rasterises Downlink's antenna glyph: a dot with two radio waves above it.

const SUBSAMPLES: u32 = 4;

/// The menu-bar glyph as straight RGBA: black with alpha (a macOS template image).
pub fn antenna_rgba(size: u32, connected: bool) -> Vec<u8> {
    let opacity = if connected { 1.0 } else { 0.35 };
    let mut rgba = vec![0u8; (size * size * 4) as usize];
    for y in 0..size {
        for x in 0..size {
            let coverage = coverage(x, y, size, |u, v| inside_antenna(u, v));
            rgba[((y * size + x) * 4 + 3) as usize] = (coverage * opacity * 255.0).round() as u8;
        }
    }
    rgba
}

/// The application icon: an accent-coloured antenna on a dark rounded square.
pub fn app_icon_rgba(size: u32) -> Vec<u8> {
    let background = [0x1d as f32, 0x1f as f32, 0x24 as f32];
    let accent = [0x4c as f32, 0xc2 as f32, 0xff as f32];
    let mut rgba = vec![0u8; (size * size * 4) as usize];
    for y in 0..size {
        for x in 0..size {
            let shape = coverage(x, y, size, inside_rounded_square);
            let glyph = coverage(x, y, size, |u, v| {
                let (gu, gv) = ((u - 0.18) / 0.64, (v - 0.14) / 0.64);
                (0.0..=1.0).contains(&gu) && (0.0..=1.0).contains(&gv) && inside_antenna(gu, gv)
            });
            let i = ((y * size + x) * 4) as usize;
            for c in 0..3 {
                rgba[i + c] = (background[c] + (accent[c] - background[c]) * glyph).round() as u8;
            }
            rgba[i + 3] = (shape * 255.0).round() as u8;
        }
    }
    rgba
}

fn coverage(x: u32, y: u32, size: u32, inside: impl Fn(f32, f32) -> bool) -> f32 {
    let mut hits = 0;
    for sy in 0..SUBSAMPLES {
        for sx in 0..SUBSAMPLES {
            let u = (x as f32 + (sx as f32 + 0.5) / SUBSAMPLES as f32) / size as f32;
            let v = (y as f32 + (sy as f32 + 0.5) / SUBSAMPLES as f32) / size as f32;
            if inside(u, v) {
                hits += 1;
            }
        }
    }
    hits as f32 / (SUBSAMPLES * SUBSAMPLES) as f32
}

/// `u`, `v` in 0..1, origin top-left.
fn inside_antenna(u: f32, v: f32) -> bool {
    let (dx, dy) = (u - 0.5, v - 0.78);
    let distance = (dx * dx + dy * dy).sqrt();
    if distance <= 0.10 {
        return true;
    }
    // Waves only in the upward wedge within 50° of vertical.
    if dy >= 0.0 || dx.abs() > -dy * 50f32.to_radians().tan() {
        return false;
    }
    (distance - 0.30).abs() <= 0.04 || (distance - 0.52).abs() <= 0.04
}

fn inside_rounded_square(u: f32, v: f32) -> bool {
    const INSET: f32 = 0.06;
    const RADIUS: f32 = 0.2;
    if !(INSET..=1.0 - INSET).contains(&u) || !(INSET..=1.0 - INSET).contains(&v) {
        return false;
    }
    let cx = u.clamp(INSET + RADIUS, 1.0 - INSET - RADIUS);
    let cy = v.clamp(INSET + RADIUS, 1.0 - INSET - RADIUS);
    (u - cx).powi(2) + (v - cy).powi(2) <= RADIUS * RADIUS
}
```

```rust
fn xml_escape(text: &str) -> String {
    text.replace('&', "&amp;")
        .replace('<', "&lt;")
        .replace('>', "&gt;")
        .replace('"', "&quot;")
        .replace('\'', "&apos;")
}

    home.join("Library/LaunchAgents").join(format!("{LABEL}.plist"))

    let path = agent_path(home);

    }
    fs::write(&path, plist(executable))?;
    Ok(path)
```

```rust
use std::fmt;

use input_source::InputSource;

/// One entry in an input-source pick list.
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum SourceChoice {
    NoChange,
    Source { id: String, name: String },
    /// Configured, but not installed or not enabled any more.
    Missing { id: String },
}

impl SourceChoice {
    pub fn id(&self) -> Option<&str> {
        match self {
            SourceChoice::NoChange => None,
            SourceChoice::Source { id, .. } | SourceChoice::Missing { id } => Some(id),
        }
    }

    pub fn is_missing(&self) -> bool {
        matches!(self, SourceChoice::Missing { .. })
    }

    pub fn options(sources: &[InputSource]) -> Vec<SourceChoice> {
        std::iter::once(SourceChoice::NoChange)
            .chain(sources.iter().map(|s| SourceChoice::Source { id: s.id.clone(), name: s.name.clone() }))
            .collect()
    }

    pub fn current(id: Option<&str>, sources: &[InputSource]) -> SourceChoice {
        let Some(id) = id else { return SourceChoice::NoChange };
        sources
            .iter()
            .find(|s| s.id == id)
            .map(|s| SourceChoice::Source { id: s.id.clone(), name: s.name.clone() })
            .unwrap_or_else(|| SourceChoice::Missing { id: id.to_owned() })
    }
}

impl fmt::Display for SourceChoice {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        match self {
            SourceChoice::NoChange => f.write_str("No change"),
            SourceChoice::Source { name, .. } => f.write_str(name),
            SourceChoice::Missing { id } => write!(f, "⚠ {id} (not installed)"),
        }
    }
}
```

```rust
//! Runs the blocking device loop on its own thread and streams its events into iced.

use std::sync::mpsc;

use futures::channel::mpsc as async_mpsc;
use futures::{SinkExt, Stream, StreamExt};
use oryx_device::{DeviceCommand, DeviceEvent, HidDiscovery, Timing};

#[derive(Debug, Clone)]
pub struct DeviceHandle(mpsc::Sender<DeviceCommand>);

impl DeviceHandle {
    pub fn shutdown(&self) {
        let _ = self.0.send(DeviceCommand::Shutdown);
    }
}

#[derive(Debug, Clone)]
pub enum DeviceMessage {
    Ready(DeviceHandle),
    Event(DeviceEvent),
}

pub fn events() -> impl Stream<Item = DeviceMessage> {
    iced::stream::channel(64, async |mut output: async_mpsc::Sender<DeviceMessage>| {
        let (command_tx, command_rx) = mpsc::channel();
        let (event_tx, mut event_rx) = async_mpsc::unbounded();
        if output.send(DeviceMessage::Ready(DeviceHandle(command_tx))).await.is_err() {
            return;
        }
        let spawned = std::thread::Builder::new().name("oryx-device".into()).spawn(move || {
            oryx_device::run(HidDiscovery::new(), Timing::default(), command_rx, |event| {
                event_tx.unbounded_send(event).is_ok()
            });
        });
        if let Err(error) = spawned {
            tracing::error!(%error, "could not start the keyboard thread");
            return;
        }
        while let Some(event) = event_rx.next().await {
            if output.send(DeviceMessage::Event(event)).await.is_err() {
                break;
            }
        }
    })
}
```

```rust
//! The menu-bar item (spec §6.1).

use companion_core::TrayView;
use futures::channel::mpsc;
use futures::{SinkExt, Stream, StreamExt};
use tray_icon::menu::accelerator::Accelerator;
use tray_icon::menu::{CheckMenuItem, IsMenuItem, Menu, MenuEvent, MenuItem, PredefinedMenuItem};
use tray_icon::{Icon, TrayIcon, TrayIconBuilder};

use crate::icon;

pub const SHOW_LAYOUT: &str = "show-layout";
pub const SETTINGS: &str = "settings";
pub const PAUSE: &str = "pause";
pub const QUIT: &str = "quit";

/// 18 pt at 2× scale.
const ICON_PX: u32 = 36;

pub struct Tray {
    icon: TrayIcon,
    status: MenuItem,
    detail: MenuItem,
    pause: CheckMenuItem,
    connected: bool,
}

impl Tray {
    /// Must run on the main thread after the event loop starts: call it from `update`.
    pub fn new() -> Result<Tray, String> {
        let status = MenuItem::new("Waiting for Voyager…", false, None);
        let detail = MenuItem::new(" ", false, None);
        let show = MenuItem::with_id(SHOW_LAYOUT, "Show Layout", true, accelerator("CmdOrCtrl+L"));
        let settings = MenuItem::with_id(SETTINGS, "Settings…", true, accelerator("CmdOrCtrl+,"));
        let pause = CheckMenuItem::with_id(PAUSE, "Pause Input Switching", true, false, None);
        let quit = MenuItem::with_id(QUIT, "Quit Downlink", true, accelerator("CmdOrCtrl+Q"));
        let menu = Menu::new();
        for item in [
            &status as &dyn IsMenuItem,
            &detail,
            &PredefinedMenuItem::separator(),
            &show,
            &settings,
            &PredefinedMenuItem::separator(),
            &pause,
            &PredefinedMenuItem::separator(),
            &quit,
        ] {
            menu.append(item).map_err(|e| e.to_string())?;
        }
        let icon = TrayIconBuilder::new()
            .with_icon(tray_icon_image(true)?)
            .with_icon_as_template(true)
            .with_menu(Box::new(menu))
            .with_tooltip("Downlink")
            .build()
            .map_err(|e| e.to_string())?;
        Ok(Tray { icon, status, detail, pause, connected: true })
    }

    pub fn apply(&mut self, view: &TrayView) {
        self.status.set_text(&view.status);
        self.detail.set_text(if view.detail.is_empty() { " " } else { view.detail.as_str() });
        self.pause.set_checked(view.paused);
        if view.connected != self.connected {
            match tray_icon_image(view.connected) {
                Ok(image) => {
                    if let Err(error) = self.icon.set_icon_with_as_template(Some(image), true) {
                        tracing::warn!(%error, "could not update the menu-bar icon");
                    }
                }
                Err(error) => tracing::warn!(%error, "could not render the menu-bar icon"),
            }
            self.connected = view.connected;
        }
    }
}

fn accelerator(spec: &str) -> Option<Accelerator> {
    spec.parse().ok()
}

fn tray_icon_image(connected: bool) -> Result<Icon, String> {
    Icon::from_rgba(icon::antenna_rgba(ICON_PX, connected), ICON_PX, ICON_PX).map_err(|e| e.to_string())
}

/// Menu item IDs as they are clicked.
pub fn menu_events() -> impl Stream<Item = String> {
    iced::stream::channel(16, async |mut output: mpsc::Sender<String>| {
        let (tx, mut rx) = mpsc::unbounded::<String>();
        MenuEvent::set_event_handler(Some(move |event: MenuEvent| {
            let _ = tx.unbounded_send(event.id.0);
        }));
        while let Some(id) = rx.next().await {
            if output.send(id).await.is_err() {
                break;
            }
        }
    })
}
```

```rust
//! Application state, messages and the effect executor.

use std::collections::{BTreeMap, BTreeSet};
use std::sync::Arc;
use std::sync::atomic::{AtomicBool, Ordering};
use std::time::Duration;

use companion_core::{Appearance, Effect, Engine, Input, LayoutState, config};
use iced::theme::Mode;
use iced::{Element, Size, Subscription, Task, Theme, system, time, window};
use input_source::{InputSource, InputSourceBackend};
use oryx_layout::LayoutCache;
use oryx_layout::client::{self, HttpClient};
use oryx_protocol::{LayoutIds, Model};

use crate::device::{self, DeviceHandle, DeviceMessage};
use crate::paths::Paths;
use crate::source_choice::SourceChoice;
use crate::tray::{self, Tray};
use crate::{layout_view, platform, settings_view, theme};

/// Set once the Quit path has run; `run()` uses it to decide on the exit safety net.
pub static QUIT_HANDLED: AtomicBool = AtomicBool::new(false);

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum WindowKind {
    Layout,
    Settings,
}

#[derive(Debug, Clone)]
pub enum Message {
    Init,
    Device(DeviceMessage),
    Menu(String),
    SystemTheme(Mode),
    WindowOpened(window::Id),
    WindowClosed(window::Id),
    PollSource,
    LayoutFetched { model: Model, ids: LayoutIds, from_cache: bool, result: Result<String, String> },
    ChipPressed(u8),
    FollowLive,
    SetLayerSource(u8, SourceChoice),
    SetFallback(SourceChoice),
    SetAppearance(Appearance),
    SetLaunchAtLogin(bool),
    RefreshLayout,
}

pub struct App {
    pub(crate) engine: Engine,
    pub(crate) paths: Paths,
    pub(crate) sources: Vec<InputSource>,
    pub(crate) system_mode: Mode,
    pub(crate) windows: BTreeMap<window::Id, WindowKind>,
    pub(crate) launch_error: Option<String>,
    pub(crate) cache: LayoutCache,
    backend: Box<dyn InputSourceBackend>,
    http: Option<HttpClient>,
    device: Option<DeviceHandle>,
    tray: Option<Tray>,
    warned_missing: BTreeSet<String>,
}

impl App {
    pub fn boot(paths: Paths) -> (App, Task<Message>) {
        let loaded = config::load(&paths.config_file);
        for warning in &loaded.warnings {
            tracing::warn!("{warning}");
        }
        let http = match client::client_builder(env!("CARGO_PKG_VERSION")).build() {
            Ok(http) => Some(http),
            Err(error) => {
                tracing::error!(%error, "HTTP client unavailable; layouts load from the cache only");
                None
            }
        };
        let app = App {
            engine: Engine::new(loaded.config),
            cache: LayoutCache::new(paths.layout_cache_dir()),
            paths,
            sources: Vec::new(),
            system_mode: Mode::None,
            windows: BTreeMap::new(),
            launch_error: None,
            backend: input_source::system_backend(),
            http,
            device: None,
            tray: None,
            warned_missing: BTreeSet::new(),
        };
        (app, Task::batch([Task::done(Message::Init), system::theme().map(Message::SystemTheme)]))
    }

    pub fn title(&self, id: window::Id) -> String {
        match self.windows.get(&id) {
            Some(WindowKind::Settings) => "Downlink Settings".into(),
            _ => match self.engine.layout() {
                LayoutState::Ready(layout) => format!("Downlink — {}", layout.title),
                _ => "Downlink".into(),
            },
        }
    }

    pub fn theme(&self, _id: window::Id) -> Option<Theme> {
        Some(theme::iced_theme(self.is_dark()))
    }

    pub(crate) fn is_dark(&self) -> bool {
        theme::is_dark(self.engine.config().appearance, self.system_mode)
    }

    pub(crate) fn source_name(&self, id: &str) -> Option<String> {
        self.sources.iter().find(|s| s.id == id).map(|s| s.name.clone())
    }

    pub fn subscription(&self) -> Subscription<Message> {
        let poll = if self.windows.is_empty() {
            Subscription::none()
        } else {
            time::every(Duration::from_secs(2)).map(|_| Message::PollSource)
        };
        Subscription::batch([
            Subscription::run(device::events).map(Message::Device),
            Subscription::run(tray::menu_events).map(Message::Menu),
            system::theme_changes().map(Message::SystemTheme),
            window::close_events().map(Message::WindowClosed),
            poll,
        ])
    }

    pub fn view(&self, id: window::Id) -> Element<'_, Message> {
        match self.windows.get(&id) {
            Some(WindowKind::Layout) => layout_view::view(self),
            Some(WindowKind::Settings) => settings_view::view(self),
            None => iced::widget::text("").into(),
        }
    }

    pub fn update(&mut self, message: Message) -> Task<Message> {
        match message {
            Message::Init => self.init(),
            Message::Device(DeviceMessage::Ready(handle)) => {
                self.device = Some(handle);
                Task::none()
            }
            Message::Device(DeviceMessage::Event(event)) => {
                tracing::debug!(?event, "device");
                self.dispatch(Input::Device(event))
            }
            Message::Menu(id) => self.on_menu(&id),
            Message::SystemTheme(mode) => {
                self.system_mode = mode;
                Task::none()
            }
            Message::WindowOpened(id) => {
                platform::activate_app();
                window::gain_focus(id)
            }
            Message::WindowClosed(id) => {
                self.windows.remove(&id);
                Task::none()
            }
            Message::PollSource => {
                self.sync_current_source();
                Task::none()
            }
            Message::LayoutFetched { model, ids, from_cache, result } => {
                self.on_layout_fetched(model, ids, from_cache, result)
            }
            Message::ChipPressed(layer) => self.dispatch(Input::PreviewLayer(Some(layer))),
            Message::FollowLive => self.dispatch(Input::PreviewLayer(None)),
            Message::SetLayerSource(layer, choice) => {
                let mut config = self.engine.config().clone();
                match choice.id() {
                    Some(id) => {
                        config.layers.insert(layer, id.to_owned());
                    }
                    None => {
                        config.layers.remove(&layer);
                    }
                }
                self.dispatch(Input::ConfigChanged(config))
            }
            Message::SetFallback(choice) => {
                let mut config = self.engine.config().clone();
                config.fallback = choice.id().map(str::to_owned);
                self.dispatch(Input::ConfigChanged(config))
            }
            Message::SetAppearance(appearance) => {
                let mut config = self.engine.config().clone();
                config.appearance = appearance;
                self.dispatch(Input::ConfigChanged(config))
            }
            Message::SetLaunchAtLogin(enabled) => match platform::set_launch_at_login(enabled) {
                Ok(()) => {
                    self.launch_error = None;
                    let mut config = self.engine.config().clone();
                    config.launch_at_login = enabled;
                    self.dispatch(Input::ConfigChanged(config))
                }
                Err(error) => {
                    tracing::warn!(%error, "could not change launch at login");
                    self.launch_error = Some(error);
                    Task::none()
                }
            },
            Message::RefreshLayout => self.dispatch(Input::RefreshLayout),
        }
    }

    fn init(&mut self) -> Task<Message> {
        platform::hide_dock_icon();
        match Tray::new() {
            Ok(tray) => self.tray = Some(tray),
            Err(error) => tracing::error!(%error, "could not create the menu-bar icon"),
        }
        if self.engine.config().launch_at_login
            && let Err(error) = platform::set_launch_at_login(true)
        {
            tracing::warn!(%error, "could not refresh the login item");
        }
        self.refresh_sources();
        self.sync_current_source();
        self.refresh_tray();
        Task::none()
    }

    fn on_menu(&mut self, id: &str) -> Task<Message> {
        match id {
            tray::SHOW_LAYOUT => self.open_window(WindowKind::Layout),
            tray::SETTINGS => {
                self.refresh_sources();
                self.open_window(WindowKind::Settings)
            }
            tray::PAUSE => {
                let paused = !self.engine.paused();
                self.dispatch(Input::SetPaused(paused))
            }
            tray::QUIT => self.dispatch(Input::Quit),
            other => {
                tracing::debug!(other, "unknown menu item");
                Task::none()
            }
        }
    }

    fn open_window(&mut self, kind: WindowKind) -> Task<Message> {
        if let Some((&id, _)) = self.windows.iter().find(|(_, k)| **k == kind) {
            platform::activate_app();
            return window::gain_focus(id);
        }
        let settings = match kind {
            WindowKind::Layout => window::Settings {
                size: Size::new(980.0, 440.0),
                min_size: Some(Size::new(640.0, 300.0)),
                ..window::Settings::default()
            },
            WindowKind::Settings => window::Settings {
                size: Size::new(560.0, 720.0),
                min_size: Some(Size::new(480.0, 420.0)),
                ..window::Settings::default()
            },
        };
        let (id, open) = window::open(settings);
        self.windows.insert(id, kind);
        open.map(Message::WindowOpened)
    }

    fn dispatch(&mut self, input: Input) -> Task<Message> {
        let effects = self.engine.handle(input);
        let mut tasks = Vec::new();
        for effect in effects {
            match effect {
                Effect::SelectInputSource(id) => self.select_source(&id),
                Effect::FetchLayout { model, ids, force } => tasks.push(self.fetch_layout(model, ids, force)),
                Effect::PersistConfig => {
                    if let Err(error) = config::save(&self.paths.config_file, self.engine.config()) {
                        tracing::error!(%error, "could not save settings");
                    }
                }
                Effect::RefreshTray => self.refresh_tray(),
                Effect::Exit => {
                    if let Some(device) = &self.device {
                        device.shutdown();
                    }
                    QUIT_HANDLED.store(true, Ordering::SeqCst);
                    tasks.push(iced::exit());
                }
            }
        }
        Task::batch(tasks)
    }

    /// Spec §8: a source that can't be selected is skipped and logged once (until it works again).
    fn select_source(&mut self, id: &str) {
        match self.backend.select(id) {
            Ok(()) => {
                self.warned_missing.remove(id);
                tracing::info!(id, "selected input source");
            }
            Err(error) => {
                if self.warned_missing.insert(id.to_owned()) {
                    tracing::warn!(%error, id, "could not select input source");
                } else {
                    tracing::debug!(%error, id, "could not select input source (already reported)");
                }
                let _ = self.engine.handle(Input::SelectFailed(id.to_owned()));
            }
        }
        self.sync_current_source();
    }

    fn sync_current_source(&mut self) {
        let current = self.backend.current().ok();
        if current.as_deref() != self.engine.current_source() {
            let _ = self.engine.handle(Input::CurrentSourceChanged(current));
            self.refresh_tray();
        }
    }

    fn refresh_sources(&mut self) {
        match self.backend.list() {
            Ok(sources) => self.sources = sources,
            Err(error) => tracing::warn!(%error, "could not list input sources"),
        }
    }

    fn refresh_tray(&mut self) {
        let view = self.engine.tray_view(|id| self.source_name(id));
        if let Some(tray) = self.tray.as_mut() {
            tray.apply(&view);
        }
    }

    fn fetch_layout(&self, model: Model, ids: LayoutIds, force: bool) -> Task<Message> {
        if !force && let Some(json) = self.cache.load(&ids) {
            return Task::done(Message::LayoutFetched { model, ids, from_cache: true, result: Ok(json) });
        }
        let Some(http) = self.http.clone() else {
            return Task::done(Message::LayoutFetched {
                model,
                ids,
                from_cache: false,
                result: Err("HTTP client unavailable".into()),
            });
        };
        let request_ids = ids.clone();
        Task::perform(
            async move {
                client::fetch_layout(&http, client::ORYX_GRAPHQL_URL, &request_ids, model.oryx_geometry())
                    .await
                    .map_err(|e| e.to_string())
            },
            move |result| Message::LayoutFetched { model, ids, from_cache: false, result },
        )
    }

    fn on_layout_fetched(
        &mut self,
        model: Model,
        ids: LayoutIds,
        from_cache: bool,
        result: Result<String, String>,
    ) -> Task<Message> {
        let parsed = match result {
            Ok(json) => match oryx_layout::parse_graphql(&json) {
                Ok(layout) => {
                    if !from_cache && let Err(error) = self.cache.store(&ids, &json) {
                        tracing::warn!(%error, "could not cache the layout");
                    }
                    Ok(Arc::new(layout))
                }
                Err(error) if from_cache => {
                    tracing::warn!(%error, "the cached layout is unreadable; fetching it again");
                    return self.fetch_layout(model, ids, true);
                }
                Err(error) => Err(error.to_string()),
            },
            Err(network) => match self.cache.load(&ids).map(|json| oryx_layout::parse_graphql(&json)) {
                Some(Ok(layout)) => {
                    tracing::info!(%network, "using the cached layout");
                    Ok(Arc::new(layout))
                }
                _ => Err(network),
            },
        };
        if let Err(error) = &parsed {
            tracing::warn!(%error, "layout unavailable");
        }
        self.dispatch(Input::LayoutLoaded { ids, result: parsed })
    }
}
```

```rust
/// Gap between neighbouring keys, in key units.

/// Places every key inside `bounds`, keeping the board's aspect ratio and centring it.
pub fn key_rects(bounds: Size, keys: &[KeyGeom], board: Size) -> Vec<Rectangle> {
    if keys.is_empty() || board.width <= 0.0 || board.height <= 0.0 || bounds.width <= 0.0 || bounds.height <= 0.0 {
        return Vec::new();
    }
    let unit = (bounds.width / board.width).min(bounds.height / board.height);
    let left = (bounds.width - unit * board.width) / 2.0;
    let top = (bounds.height - unit * board.height) / 2.0;
    let gap = unit * KEY_GAP;
    keys.iter()
        .map(|key| Rectangle {
            x: left + key.x * unit + gap / 2.0,
            y: top + key.y * unit + gap / 2.0,
            width: unit - gap,
            height: unit - gap,
        })
        .collect()
}

}

            align_y: alignment::Vertical::Center,
            ..canvas::Text::default()
        });
```

```rust
        pick_list(options.clone(), Some(fallback), Message::SetFallback).width(240).into(),
    );

    let appearance = row![
        appearance_button("System", Appearance::System, config.appearance, colors),
        appearance_button("Light", Appearance::Light, config.appearance, colors),
        appearance_button("Dark", Appearance::Dark, config.appearance, colors),
    ]
    .spacing(2);
    let mut general = column![
        setting_row(text("Appearance").into(), appearance.into()),
        setting_row(
            text("Launch at login").into(),
            toggler(config.launch_at_login).on_toggle(Message::SetLaunchAtLogin).into(),
        ),
    ];
    if let Some(error) = &app.launch_error {
        general = general.push(text(error.clone()).size(12).color(colors.danger));
    }

    scrollable(
        column![
            section("Input source per layer", layer_rows.into(), TRANSIENT_NOTE, colors),
            section("When the keyboard disconnects or Downlink quits", fallback_row, "", colors),
            section("General", general.into(), "", colors),
            section("Keyboard", keyboard_section(app, colors), "", colors),
        ]
        .spacing(18)
        .padding(18),
    )
    .into()
}

/// Every layer of the loaded layout; without one, the configured and live layers.
fn layer_indices(app: &App) -> Vec<u8> {
    if let LayoutState::Ready(layout) = app.engine.layout() {
        return layout.layers.iter().map(|l| l.index).collect();
    }
    let mut indices: BTreeSet<u8> = app.engine.config().layers.keys().copied().collect();
    indices.extend(app.engine.active_layer());
    if indices.is_empty() {
        indices.extend(0..3);
    }
    indices.into_iter().collect()
}

fn keyboard_section(app: &App, colors: Colors) -> Element<'_, Message> {
    let engine = &app.engine;
    let (summary, details, ids) = match engine.connection() {
        Connection::Connected { model, ids, protocol } => {
            let title = match engine.layout() {
                LayoutState::Ready(layout) => layout.title.clone(),
                _ => "—".into(),
            };
            let revision = ids.as_ref().map(|i| i.revision_id().to_owned()).unwrap_or_else(|| "unknown".into());
            let protocol = protocol.map(|p| format!("protocol v{p}")).unwrap_or_else(|| "protocol ?".into());
            (format!("{} · {title}", model.name()), format!("rev {revision} · {protocol}"), ids.clone())
        }
        _ => ("Not connected".to_owned(), String::new(), None),
    };
    let cached = ids
        .as_ref()
        .and_then(|ids| app.cache.modified(ids))
        .map(|time| format!("cached {}", format_age(SystemTime::now().duration_since(time).unwrap_or_default())))
        .unwrap_or_else(|| "not cached".into());
    let refresh = button(text("Refresh from Oryx").size(12)).on_press_maybe(ids.is_some().then_some(Message::RefreshLayout));
    column![
        setting_row(text(summary).into(), text(details).color(colors.sub_text).into()),
        setting_row(
            text("Layout data").into(),
            row![text(cached).color(colors.sub_text), refresh].spacing(8).align_y(Center).into(),
        ),
    ]
    .into()
}

fn section<'a>(title: &'a str, body: Element<'a, Message>, note: &'a str, colors: Colors) -> Element<'a, Message> {
    let card = container(body).padding([4, 12]).width(Fill).style(move |_theme: &Theme| container::Style {
        background: Some(colors.panel.into()),
        border: Border { color: colors.border, width: 1.0, radius: 9.0.into() },
        ..container::Style::default()
    });
    let mut content = column![text(title.to_uppercase()).size(12).color(colors.sub_text), card].spacing(6);
    if !note.is_empty() {
        content = content.push(text(note).size(11).color(colors.sub_text));
    }
    content.into()
}

fn setting_row<'a>(label: Element<'a, Message>, control: Element<'a, Message>) -> Element<'a, Message> {
    row![container(label).width(Fill), control].align_y(Center).padding([6, 0]).into()
}

fn appearance_button<'a>(label: &'a str, value: Appearance, current: Appearance, colors: Colors) -> Element<'a, Message> {
    let selected = value == current;
    button(text(label).size(12))
        .padding([2, 12])
        .on_press(Message::SetAppearance(value))
        .style(move |_theme: &Theme, _status: button::Status| button::Style {
            background: Some(if selected { colors.accent } else { colors.key }.into()),
            text_color: if selected { colors.on_accent } else { colors.key_text },
            border: Border { radius: 6.0.into(), ..Border::default() },
            ..button::Style::default()
        })
        .into()
}

/// "just now", "5 min ago", "3 h ago", "1 day ago", "2 days ago".
pub fn format_age(age: Duration) -> String {
    let secs = age.as_secs();
    match secs {
        0..60 => "just now".into(),
        60..3600 => format!("{} min ago", secs / 60),
        3600..86_400 => format!("{} h ago", secs / 3600),
        _ => match secs / 86_400 {
            1 => "1 day ago".into(),
            days => format!("{days} days ago"),
        },
    }
}
```

```rust
//! Writes the PNGs of a macOS .iconset: cargo run -p downlink --bin make-icons -- <dir>.iconset
use std::fs::File;
use std::io::BufWriter;
use std::path::PathBuf;

const SIZES: [(&str, u32); 10] = [
    ("icon_16x16", 16),
    ("icon_16x16@2x", 32),
    ("icon_32x32", 32),
    ("icon_32x32@2x", 64),
    ("icon_128x128", 128),
    ("icon_128x128@2x", 256),
    ("icon_256x256", 256),
    ("icon_256x256@2x", 512),
    ("icon_512x512", 512),
    ("icon_512x512@2x", 1024),
];

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let dir = PathBuf::from(std::env::args().nth(1).ok_or("usage: make-icons <output .iconset directory>")?);
    std::fs::create_dir_all(&dir)?;
    for (name, size) in SIZES {
        let rgba = downlink::icon::app_icon_rgba(size);
        let file = BufWriter::new(File::create(dir.join(format!("{name}.png")))?);
        let mut encoder = png::Encoder::new(file, size, size);
        encoder.set_color(png::ColorType::Rgba);
        encoder.set_depth(png::BitDepth::Eight);
        encoder.write_header()?.write_image_data(&rgba)?;
    }
    Ok(())
}
```

```bash
# Builds target/bundle/Downlink.app (ad-hoc signed). Usage: packaging/macos/bundle.sh [output-dir]

codesign --force --deep --sign - "$APP"
echo "Built $APP (version $VERSION)"
```

`README.md`:

````markdown
# Downlink

A small menu-bar app for the **ZSA Voyager** keyboard:

- **Live layout view.** Shows the layout flashed on your keyboard, follows the active layer and highlights the keys you press.
- **Per-layer input-source switching.** For example: Main → English, RO layer → Romanian, HU layer → Hungarian. Transient layers (Navigation, Symbols, …) leave the input source alone.
- **Reconnects by itself** after sleep, wake and replugging.
- **Follows macOS Light/Dark** automatically.

Downlink talks to the keyboard directly over USB. You don't need Keymapp running.

> Downlink is an independent project. It is **not affiliated with or endorsed by ZSA Technology Labs**.
> "ZSA", "Voyager", "Oryx" and "Keymapp" are used only to describe compatibility.

## Requirements

- macOS 13 or newer (Linux support is planned)
- A ZSA Voyager running Oryx firmware (any layout built in Oryx)
- To build: Rust stable ≥ 1.90 (`rustup`) and Xcode Command Line Tools

## Build and install

```bash
packaging/macos/bundle.sh
cp -R target/bundle/Downlink.app /Applications/
open /Applications/Downlink.app
```

The antenna icon appears in the menu bar. Open **Settings…** to choose an input source for each
layer and the fallback used when the keyboard disconnects or Downlink quits. Turn on **Launch at
login** there, too.

## Moving over from Keymapp and a layout-switcher script

1. Quit Keymapp and turn off its "start at login" option, or uninstall it. While Keymapp holds
   the keyboard, Downlink may not be able to open it.
2. If you used a script or service that switched input sources from Keymapp's API, unload it,
   for example `launchctl unload ~/Library/LaunchAgents/<its label>.plist`.
3. Open Downlink's Settings and map your layers.

## Configuration

Settings are saved in `~/Library/Application Support/Downlink/config.toml`:

```toml
appearance = "system"          # "system" | "light" | "dark"
launch_at_login = true

[switching]
fallback = "com.apple.keylayout.US"

[switching.layers]               # keyed by Oryx layer index; unlisted layers don't switch
"0" = "com.apple.keylayout.US"
"1" = "com.apple.keylayout.Romanian-Standard"
```

To list the input-source IDs on your Mac: `cargo run -p input-source --example list`.

- Layout data is fetched once per revision from Oryx and cached in `~/Library/Caches/Downlink/`.
- Logs are in `~/Library/Logs/Downlink/`. Set `DOWNLINK_LOG=debug` for more detail.
````
